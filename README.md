# 📊 Student Analytics Platform - Python Folder

Welcome to the **Student Analytics Platform**! This folder contains all the core Python scripts, Jupyter notebooks, and resources for analyzing student engagement, performance, and demographic trends at UWE Bristol.

---

## 📁 Folder Structure

```
python_folder/
├── csv_data/                # Raw and processed CSV/Excel datasets
├── images/                  # Visualizations and charts for reports
├── etl_script.py            # ETL pipeline for data cleaning and integration
├── data_cleaning_one.ipynb  # Jupyter notebook for cleaning and merging all weeks of data set on
├── data_cleaning_o2.ipynb   # Jupyter notebook for cleaning and merging all weeks of data set on
```

---

## 🚀 Key Files & Their Purpose

- **etl_script.py**
  - Main ETL pipeline for cleaning, merging, and transforming student data.
  - Handles missing values, duplicate removal, and feature engineering.

- **data_cleaning_one.ipynb**
  - Jupyter notebook for step-by-step data cleaning and exploratory analysis.
  - Includes code for column renaming, type conversion, and initial statistics.

- **demo_week_dataone.csv, merged_datatwo.csv, merged_demography.csv, new.csv**
  - Example and processed datasets for analysis and modeling.

## 🛠️ How to Use

1. **Clone the repository:**
   ```bash
   git clone https://github.com/<your-username>/UWE_Brsitol_IGP_Project.git
   cd UWE_Brsitol_IGP_Project/python_folder
   ```
2. **Install dependencies:**
   ```bash
   pip install -r requirements.txt
   ```
3. **Run ETL script:**
   ```bash
   python etl_script.py
   ```
4. **Open and run notebooks:**
   - Use JupyterLab or VS Code to open `data_cleaning_one.ipynb` and other notebooks for interactive analysis.

---

## 📦 Requirements

- Python 3.8+
- pandas, numpy, matplotlib, seaborn, openpyxl
- JupyterLab or VS Code (recommended for notebooks)
