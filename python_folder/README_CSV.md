# 📑 CSV Files Documentation (python_folder)

This README describes all the CSV files located directly in the `python_folder` directory (not in the `csv_data` subfolder). These files are used for student analytics, performance analysis, and data integration in the UWE Bristol IGP Project.

---

## 📁 Location: `python_folder/`

### CSV Files:
- `demo_numeric.csv` — Numeric student demographic and engagement data
- `demo_week_2_numeric.csv` — Week 2 numeric engagement and demographic data
- `demo_week_2.csv` — Week 2 categorical engagement and demographic data
- `demo.csv` — General student demographic and engagement data
- `merged_df.csv` — Merged dataset for analysis
- `merged_df2.csv` — Secondary merged dataset for analysis
- `merged_weeks.csv` — Combined weekly student activity data
- `merged_weeks2.csv` — Alternative combined weekly activity data
- `new.csv` — Additional processed student data
- `Retro_numeric.csv` — Retrospective numeric scores and engagement
- `Retrospective.csv` — Retrospective categorical and survey data
- `students_info.csv` — Student information and demographic details
- `students_info2.csv` — Alternative student information dataset

---

## 🗂️ File Descriptions

- **demo_numeric.csv / demo_week_2_numeric.csv / demo_week_2.csv / demo.csv**
  - Student demographic and engagement data in both numeric and categorical formats.
  - Useful for statistical analysis, machine learning, and reporting.

- **merged_df.csv / merged_df2.csv / merged_weeks.csv / merged_weeks2.csv / new.csv**
  - Merged and processed datasets for advanced analytics and modeling.
  - Combine multiple sources (demographics, engagement, performance).

- **Retro_numeric.csv / Retrospective.csv**
  - Retrospective student performance and engagement data.
  - Numeric scores, survey responses, and qualitative metrics.

- **students_info.csv / students_info2.csv**
  - Student information, demographic details, and identifiers.
  - Used for joining and merging with other datasets.

---

## 🛠️ Usage

- Use these CSV files as input for ETL scripts, data cleaning notebooks, and analysis workflows.
- All files are UTF-8 encoded and compatible with pandas, Excel, and most data tools.
- For column details, see the header row in each file or refer to the main project documentation.
